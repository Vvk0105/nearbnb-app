# Reporting a bug

Copy this into a GitHub issue (or a message). One bug per report. Screenshots help more than anything else.

```
Title: <short: what is wrong, on which screen>

Screen: <e.g. Trips > trip detail>
Phone and Android version: <e.g. Pixel 7, Android 14>
App version: <the version in pubspec.yaml, e.g. 0.1.0+1>
Signed in as: <guest test account email, never a password>

Steps:
1.
2.
3.

What happened:

What I expected:

Error text on screen (copy it exactly):

Screenshot / screen recording: <attach>

Build or run errors (if the app does not build): <paste the first error from `flutter analyze` / `flutter run`>
```

**Severity**
- **Blocker:** cannot sign in, search, book or pay; the app crashes.
- **Major:** a feature gives a wrong result (wrong price, wrong date, wrong status).
- **Minor:** layout, wording, colours.

Never paste passwords, card numbers or API keys into a report.
